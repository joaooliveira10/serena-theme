# Changelog

## 1.0.0

Primeira versão pública.

- Temas de cores **Serena Dark**, **Serena Dark Vivid**, **Serena Light**, **Serena Light Vivid**, **Serena High Contrast** e **Serena High Contrast Light**, com as mesmas cores para o mesmo papel em todas as variantes.
- Cobertura revisada para C#, Java, JavaScript, TypeScript, Go, Python e YAML, incluindo realce semântico (Roslyn, Pylance, TypeScript/tsgo, gopls).
- Cobertura de mais 30 linguagens: Rust, C, C++, Kotlin, Swift, Dart, Scala, Groovy, Zig, PHP, Ruby, Lua, R, Elixir, Perl, Bash, PowerShell, SQL, Vue, Svelte, Astro, Angular, Dockerfile, Makefile, TOML, INI, Terraform/HCL, GraphQL, XML, Markdown e CSS/SCSS/Less.
- Interface completa: chat de IA, sugestões inline, testes, notebooks, merge, terminal, grafo do Git e barra de status nas cores da paleta.
- Colchetes coloridos em 6 níveis, com guias de pares na mesma cor.
- Tema de ícones em duas edições, com 284 tipos de arquivo e 101 pastas, e versão de alto contraste:
  - **Serena Icons**: logos reconhecíveis em 81 tipos de arquivo, redesenhados na paleta (onde as regras da marca permitem).
  - **Serena Icons Minimal**: só desenhos originais.
- Arquivos de configuração (Svelte, Astro, Vue, Yarn, pnpm, Bun, Swift, Godot e outros) com ícone de configuração próprio.
- Modelos de issue e verificação automática do build no GitHub.
